Installer l'extension « Envoyer à Inspi »

Elle fonctionne sur Google Chrome et sur Microsoft Edge (même fichier).

  1. La page Extensions du navigateur s'ouvre, ainsi que le dossier de l'extension.
  2. Active le Mode développeur (Chrome : en haut à droite · Edge : dans le panneau de gauche).
  3. Clique Charger l'extension non empaquetée et choisis ce dossier (son chemin est déjà copié, colle‑le avec Ctrl+V) :
    {{FOLDER}}
  4. C'est tout : l'extension se connecte toute seule à Inspi. Fais un clic droit sur n'importe quelle image → Envoyer à Inspi.

Astuce : épingle l'icône orange Inspi dans la barre du navigateur (icône puzzle → épingle). Au démarrage, Chrome/Edge peut afficher « Désactiver les extensions en mode développeur » : clique sur la croix pour la garder.
