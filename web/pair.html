Inspi

Appairer ton iPhone

L'iPhone et le PC doivent être sur le même Wi‑Fi. Rien ne passe par Internet.

{{QR}}

Scanne avec l'appareil photo de l'iPhone

1Scanne le QR code

  1. Ouvre l'appareil photo, vise le QR code, touche le lien jaune.
  2. Safari ouvre la page Envoyer à Inspi : ton iPhone est appairé.
  3. Dans Safari : Partager → Sur l'écran d'accueil pour en faire une appli.

Si la page ne s'ouvre pas : autorise Python dans le pare‑feu Windows (réseau privé), et vérifie que ton Wi‑Fi est réglé en « réseau privé » dans Windows.

2Crée le Raccourci « Inspi » (envoi en un geste)

Il ajoute Inspi dans le menu Partager de toutes les applis (Photos, Pinterest, Instagram, Safari…). Tu peux partager une image, une vidéo ou un lien : pour un lien, le PC va chercher l'image de la page lui‑même (l'original HD pour Pinterest).

URL{{BASE}}/api/capture En‑têteBearer {{TOKEN}}

Astuce : copie ces deux valeurs dans une note Apple partagée, ou envoie‑les‑toi par AirDrop, pour les coller sur l'iPhone.

  1. App Raccourcis → ＋ → nomme‑le Inspi.
  2. Touche ⓘ (en bas) → active Afficher dans la feuille de partage. En haut, dans « Recevoir », garde Images, Médias, Texte, URL, Pages web Safari (Médias = les vidéos). Si aucune entrée : Demander → Photos.
  3. Ajoute l'action Répéter avec chaque élément de Entrée du raccourci.
  4. Dedans, ajoute Obtenir le contenu de l'URL :
    • URL : colle l'URL ci‑dessus
    • Méthode : POST
    • En‑têtes : clé Authorization, valeur : colle l'en‑tête ci‑dessus
    • Corps de la requête : Formulaire
      • champ Fichier, clé file, valeur Élément de répétition
      • champ Texte, clé source, valeur iphone
  5. Après la boucle : Afficher la notification « Envoyé à Inspi ✓ ».

Bonus capture d'écran : duplique le raccourci, remplace l'entrée par l'action Prendre une capture d'écran, puis Réglages → Accessibilité → Toucher → Toucher le dos → Toucher deux fois → ce raccourci. Deux tapes au dos de l'iPhone = capture envoyée au PC.
